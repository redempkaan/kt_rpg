# Kotlin Console RPG Game
This project is a console-based, turn-based RPG battle simulation developed using the Kotlin programming language.   

The game features pre-defined characters and bosses, and the user can select any two from these groups to battle each other. All inputs and outputs are handled through the console.

# Features

- **Pre-built Characters:** The game includes pre-defined heroes with different abilities.

- **Pre-built Bosses:** Powerful boss characters are ready for battle.

- **Turn-Based Battle System:** Battles progress in a classic RPG style, where each player takes turns making a move.

- **Console Interface:** All user interaction (character selection, attacks, battle status) is provided via the console.

# How to Play

**1) Run the Project:** When you run the project in your IDE (e.g., IntelliJ IDEA), the game will start automatically.

**2) Select Combatants:** The console will prompt you to choose the fighters for the battle from the available character and boss lists.

**3) Start the Battle:** After your selections, the battle begins, and the console will show you what happens in each turn.

**4) End of Battle:** The battle ends when one character's health drops to zero, and the winner is announced on the screen.

# How to Set Up and Run

- Clone the project.

- Open IntelliJ IDEA and import the project.

- Find the main.kt file and press the Run button to start the game.
